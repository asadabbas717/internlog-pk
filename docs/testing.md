# Verification

Run `npm ci`, `npm run check`, `npx playwright install chromium`, `npm run test:e2e`, and `npm audit --audit-level=high`. Linux CI installs browser OS dependencies with `npx playwright install --with-deps chromium`. Browser downloads need network access. Tests use synthetic content and no accounts. The Playwright web server always builds production output first; `npm run dev` deliberately has no service worker.

`check` runs typecheck, zero-warning ESLint, Prettier, Vitest V8 coverage and production build. The unit suite checks unsupported, development, success, failed and stalled registration. Integration tests verify truthful feature boundaries, semantic landmarks and privacy notices. Browser tests exercise keyboard skip navigation, desktop/mobile layout, axe WCAG A/AA rules, explicit cache contents and offline reopening under a repository subpath. Automated axe results do not replace a full accessibility audit. Generated reports are ignored by Git.

Coverage includes app and infrastructure source; the React root bootstrap is excluded because browsers exercise it. Domain coverage gates require >=95% statements/lines/functions and >=90% branches. Domain tests cover real/invalid calendars (including years below 100, leap centuries and year boundaries), integer-minute precision, target/entry/text/URL limits, duplicate IDs, aggregate daily limits, deterministic grouping and excess progress. Codec tests cover Unicode round-trips, hostile markup as plain text, malformed/unknown envelopes and UTF-8 size limits. Do not inflate coverage with trivial implementation-mirroring tests.

IndexedDB integration tests use fake-indexeddb with a fresh factory per test. They cover initial schema upgrade 0→1, reload, edits/deletes, current data validation, conflicts/concurrent writers, missing/corrupt records, quota and abort rollback, incompatible schemas/future versions, denied storage, initialization failure, and late timed-out opens. The blocked-event guard is explicitly simulated: schema v1 has no prior released schema whose connection could block a 0→1 upgrade. Quota/abort injection tests failure behavior, not physical disk exhaustion.

Playwright additionally starts a development server on port 4174. A test-only module fixture imports the actual adapter; Chromium verifies page reload persistence, offline read/write/connection reopening and native cross-tab conflict handling. Production shell/offline tests continue on port 4173. The harness is not imported by the app and is absent from dist. Offline browser reopening of the public shell and offline storage operations are separate checks until Phase 2 connects storage to the UI.

Pending release checks: physical Android/low-end device, Safari/Firefox, screen reader, contrast/zoom/reflow review, installation UX, storage eviction, worker update lifecycle and deployed GitHub Pages behavior. These are not implied by passing Chromium emulation. No legacy migration exists yet; test preserving migrations whenever a real schema changes. Phases 2–3 add student workflows, public storage wiring and backups. Record dated actual outcomes in PROJECT_CONTEXT.md; never carry forward passing claims after relevant changes.
